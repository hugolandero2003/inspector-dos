# 📸 INSTRUCCIONES PARA SUBIR IMÁGENES AL CARRUSEL

## 📁 Carpeta de Destino
```
/public/carousel-images/
```

## 🖼️ Imágenes Necesarias

Sube **3 imágenes** con estos nombres exactos:

1. **banner-1.jpg** - Primera imagen del carrusel
2. **banner-2.jpg** - Segunda imagen del carrusel  
3. **banner-3.jpg** - Tercera imagen del carrusel

## 📋 Especificaciones Recomendadas

- **Formato**: JPG o PNG
- **Tamaño recomendado**: 1200x540px (proporción 2.22:1)
- **Tamaño máximo**: 2MB por imagen
- **Contenido**: Imágenes reales de operaciones, flotas, inspecciones, dashboards, etc.

## ⚙️ Cómo Funciona

- ✅ El carrusel cambia automáticamente cada **5 segundos**
- ✅ Tiene **puntos indicadores** interactivos (clickea para ir a una imagen específica)
- ✅ Transición suave entre imágenes (fade-in/fade-out 800ms)
- ✅ Los puntos azules indican la imagen actual
- ✅ Responsive en todos los dispositivos

## 🚀 Ejemplo de Contenido para las Imágenes

- **banner-1.jpg**: Pantalla del dashboard con inspecciones
- **banner-2.jpg**: Flota de vehículos en operación
- **banner-3.jpg**: Supervisor validando inspecciones en tablet

## 📝 Notas

- Solo necesitas 3 imágenes
- Puedes cambiar las imágenes en cualquier momento (reemplaza los archivos)
- El carrusel se reiniciará automáticamente
- No necesitas hacer nada en el código, todo es automático

¡Sube las imágenes y listo! 🎬
